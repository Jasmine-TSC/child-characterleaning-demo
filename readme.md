# 儿童识字小报生成器

一款基于 AI 的儿童趣味识字小报生成工具，帮助家长和老师快速创建适合 5-9 岁儿童的学习小报。

## 功能特点

- **智能词汇联想** - 根据选定主题自动生成 15-20 个相关词汇（拼音+汉字）
- **一键生成** - 输入主题和标题，即可生成精美的儿童识字小报图片
- **多种场景** - 支持超市、医院、公园、学校、餐厅、游乐场等常用场景
- **自定义主题** - 支持输入自定义主题，灵活扩展

## 使用方法

### 1. 准备 API Key

访问 [kie.ai/api-key](https://kie.ai/api-key) 获取 Nano Banana Pro API Key

### 2. 打开页面

直接在浏览器中打开 `index.html` 文件

### 3. 输入设置

- 输入 API Key（会自动保存到本地）
- 选择主题/场景（或输入自定义主题）
- 输入小报标题（如：《走进超市》）

### 4. 生成图片

点击"生成图片"按钮，等待 AI 生成完成

### 5. 下载使用

生成完成后可点击"下载图片"保存到本地

## 支持的场景

| 场景 | 说明 |
|------|------|
| 超市 | 收银员、货架、购物车、苹果、牛奶等 |
| 医院 | 医生、护士、病床、体温计、救护车等 |
| 公园 | 爬梯、秋千、风筝、鸽子、花草等 |
| 学校 | 老师、学生、教室、黑板、书包等 |
| 餐厅 | 服务员、厨师、碗筷、菜单等 |
| 游乐场 | 摩天轮、旋转木马、冰淇淋等 |
| 自定义 | 输入任意主题，自动联想相关词汇 |

## 技术架构

- **前端**: 纯 HTML + CSS + JavaScript，无外部依赖
- **AI 模型**: Nano Banana Pro（via Kie AI API）
- **图片比例**: 3:4（竖版 A4 风格）
- **输出格式**: PNG
